Noter

Per-save tasks with editing, completion, ordering and map pins. Supports mouse and controller navigation.

Open from the mod toolbar. Click a note to show its actions and a wrapped preview; double-click or choose Edit to change the full text.

Mark notes complete, hide completed notes, and reorder them within their completion group. Use Set point to attach a map position; the pin beside the note returns the camera to it. Escape, right-click, Cancel, or closing Noter cancels point selection.

New and edited notes are limited to 500 Unicode characters. Existing longer notes are preserved; shorten them to 500 characters before saving an edit.

The window is movable and pinnable, with normal and expanded sizes. Switching sizes preserves drafts and task selection.

The Remember mod parameter has two options:

  • Remembered (default): saves the normal window position and normal/expanded choice for each save. Expanded windows reopen centred; their position is not saved.
  • Ephemeral: resets size and position when the window closes. Notes, pin and Hide completed preferences are still saved.

Enable Opaque window in the mod parameters for a solid background; it is off by default.

Save the game to keep notes and preferences across sessions. A fresh save starts with the defaults. Removing Noter may discard its data.

Text input on consoles has not been tested.

简体中文

每个存档都有独立的任务，支持编辑、完成标记、排序和关联地图位置。从模组工具栏打开 Noter。记忆模式（默认）保留普通窗口的位置及普通或展开状态；展开窗口重新打开时居中。临时模式在关闭时重置大小和位置。不透明窗口可启用实色背景。保存游戏以在下次游玩时保留笔记和偏好设置；新存档从默认设置开始。移除模组可能导致其数据丢失。

繁體中文

每個存檔都有獨立的任務，支援編輯、完成標記、排序和關聯地圖位置。從模組工具列開啟 Noter。記憶模式（預設）保留一般視窗的位置及一般或展開狀態；展開視窗重新開啟時置中。暫時模式在關閉時重設大小和位置。不透明視窗可啟用實色背景。儲存遊戲以在下次遊玩時保留筆記和偏好設定；新存檔從預設設定開始。移除模組可能導致其資料遺失。

When reporting an issue, please share your stdout.txt log so I can understand the error and check whether another mod is involved. You can find it in the crash_dump folder inside the game's userdata folder; see the wiki's log file guide. The log resets whenever the game starts, so copy it before restarting. After a crash, use the timestamped log from that crash.

Upload the log to Pastebin, SwissTransfer, or another file host, then share the link with your report.
