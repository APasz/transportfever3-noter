Noter

Per-save tasks with editing, completion, ordering and map pins. Supports mouse and controller navigation.

Open from the mod toolbar. Click a note to show its actions and a wrapped preview; double-click or choose Edit to change the full text.

New and edited notes are limited to 500 Unicode characters. Existing longer notes are preserved; shorten them to 500 characters before saving an edit.

The window is movable and pinnable, with normal and expanded sizes. Enable Opaque window in the mod parameters for a solid background; it is off by default.

Save the game to keep notes; removing Noter may discard them.

Text input on consoles has not been tested.

When reporting an issue, please share your stdout.txt log so I can understand the error and check whether another mod is involved. You can find it in the crash_dump folder inside the game's userdata folder; see the wiki's log file guide. The log resets whenever the game starts, so copy it before restarting. After a crash, use the timestamped log from that crash.

Upload the log to Pastebin, SwissTransfer, or another file host, then share the link with your report.
