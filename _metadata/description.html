Noter

Per-save tasks with editing, completion, ordering and map pins. Supports mouse and controller navigation, with translations for all 13 game languages.

Open from the mod toolbar. Click a note to show its actions and a wrapped preview; double-click or choose Edit to change the full text.

New and edited notes are limited to 500 Unicode characters. Existing longer notes are preserved; shorten them to 500 characters before saving an edit.

The window is movable and pinnable, with normal and expanded sizes. Enable Opaque window in the mod parameters for a solid background; it is off by default.

Save the game to keep notes; removing Noter may discard them.

Text input on consoles has not been tested.
